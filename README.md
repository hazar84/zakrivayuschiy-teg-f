# Закрывающий тег

Адаптивная веб-страница с элементами анимации на кнопках лайка.

## 📋 Описание проекта

**Закрывающий тег** - проект по веб-разработке с фокусом на качественную адаптивную верстку, современные CSS-технологии и доступность. Проект демонстрирует профессиональный подход к созданию веб-страниц с соблюдением всех современных стандартов.

## 🎯 Ключевые особенности

### 🎨 Визуальное соответствие
- **Точное соответствие макету** в Firefox, Google Chrome и Yandex Browser
- **Адаптивный дизайн** для всех размеров экранов
- **Pixel Perfect** верстка с минимальными отклонениями
- **Стабильная сетка** без "ломки" между брейкпоинтами

### 🛠️ Технологический стек
- **HTML5** - семантическая разметка
- **CSS3** - современные стили и анимации
- **Flexbox/Grid** - современные методы верстки
- **БЭМ** - методология именования классов
- **SVG** - векторная графика

## 🚀 Реализованная функциональность

### 🎪 Анимации и эффекты
- **Плавные трансформации** с конкретными изменяемыми свойствами
- **Mix-blend-mode** для кнопок и текстовых эффектов
- **CSS-фильтры** для изображений карточек (минимум 7 разных фильтров)
- **Text-stroke** и **text-shadow** с поддержкой `@supports`
- **Вариативный шрифт Inter** с правильными настройками

### 📱 Адаптивность
- **Mobile-first** подход
- **Резиновая верстка** между брейкпоинтами
- **Отсутствие горизонтального скролла**
- **Корректное отображение** на всех устройствах

### 🎯 Интерактивные элементы
- **Состояния hover и focus-visible** для всех интерактивных элементов
- **Модальное окно** на элементе `<dialog>` с backdrop
- **Плавные цветовые переходы** через mix-blend-mode
- **Доступная навигация** с правильной семантикой

## 📦 Быстрый старт

### Установка и запуск

**1. Клонирование репозитория**
```bash
git clone https://github.com/hazar84/zakrivayuschiy-teg-f.git
```

**2. Переход в папку проекта**
```bash
cd zakrivayuschiy-teg-f
```

**3. Запуск через Live Server**
- Запустите VS Code:
- Установите расширение "Live Server"
- Правой кнопкой на index.html → "Open with Live Server"

## 🎨 Особенности реализации

### 🔤 Типографика
- Inter - вариативный шрифт с диапазоном начертаний
- PressStart2P - пиксельный шрифт для акцентов
- Правильные форматы woff2 с поддержкой вариаций
- Font-variation-settings для точного контроля

### 🖼️ Графика
- SVG иконки с инлайновой вставкой для анимаций
- Символьные спрайты через <symbol> + <use>
- Растровые изображения только для карточек
- CSS-фильтры для стилизации изображений

### 🎭 Визуальные эффекты
- Фиксированный фон с градиентами
- Mix-blend-mode для интерактивных элементов
- Text-stroke с fallback на text-shadow

### 📐 Технические стандарты
